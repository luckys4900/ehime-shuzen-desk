  1. PHASE 1受付・確認

    1. 案件受付送信後の画面に受付番号を表示し、担当者から、ご指定の電話またはメールに受付のご連絡をします。
    2. 内容確認写真・所在地・ご希望の時期を確認します。
    3. 対応可否の確認対応できる{{p_partner}}を確認し、対応可否と次のステップをご案内します。
    4. 必要情報の追加確認判断に足りない情報があれば、お問い合わせします。

  2. PHASE 2現地調査・見積

    1. 現地調査の要否判断写真で判断できるか、現地調査が必要かをお知らせします。
    2. 現地調査日の調整現地調査が必要な場合は、候補日を調整します。
    3. 見積提出予定のご案内見積までに時間が必要な案件は、先に提出予定をお知らせします。
    4. 正式見積必要な現地確認と{{p_partner}}の判断を経て、内訳つきの見積を提出します。

  3. PHASE 3発注・{{p_work}}

    1. 発注見積をご確認・ご承認いただいてから発注となります。{{p_work}}可能な時期もご案内します。御社
    2. {{p_work}}{{p_partner}}が{{p_work}}します。予定の変更や確認が必要なことは、当デスクからご連絡します。{{p_partner}}

  4. PHASE 4完了

    1. 完了確認見積の項目どおりに終わっているかを確認します。
    2. 写真報告前後の写真と完了報告を、メールなどご指定の方法でお送りします。手直しのご連絡も当デスクが窓口です。

所要日数は、案件の内容と{{p_partner}}の状況によって異なります。そのため一律の日数はお約束せず、段階ごとに予定をご案内します。正式な見積は、必要な現地確認と{{p_partner}}の判断を経てから提出します。
