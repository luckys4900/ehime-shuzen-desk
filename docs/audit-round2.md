## カテゴリ別の評価理由

### Visual 16 / 20
良い点
- 全幅の写真ヒーロー、明朝の大見出し、罫線で組んだ情報、`hero__foot`（業種別の入口＋「写真はイメージです」の帯）、写真とパネルの重ね、3 分割のフル幅タイル。イズミ装美（01）と同じ文法の、施工会社のコーポレートサイトらしい上質な構成になった。色は濃緑・生成り・錆朱で、青紫・グラスモーフィズムはない。角丸はゼロ。カードグリッドに頼っていない。
- 1440px のファーストビューは、参照サイトと並べても見劣りしない。

減点理由
- **写真の出自が明らかに海外**: `kitchen`（米国式 Type B コンセント・御影石のカウンター、`kanri.html:34`）、`hero`／`room` 系の米国住宅（クラウンモールディング・ブラインド）、`worker`／`partner`（米国カレッジの廊下・EXIT 表示・ヘルメット姿の作業員）。松山の管理会社が見ると「この会社の写真ではない」と同時に「愛媛の物件と雰囲気が違う」と感じる。参照サイト（01）の国内マンション写真に比べて、リアリティが一段落ちる。
- **写真の質のばらつき**: Flickr の 1024px 素材は解像度・色かぶり（`office` は緑かぶり）・夜景（`shop` は夜の古い町家の外観）にばらつきがある。Pexels の 1600px 素材と並ぶと質の差が見える。
- **同じ写真の使い回し**: `hero` を TOP ヒーローと `kaitori.html:157` で再使用している。
- **見出しの泣き別れ**: 1440px で「案件ごとに、受けるかどうかを選べま／す」（`partner.html:137`）、「買取再販事業者様／からの／よくあるご質問」（`kaitori.html:221`）、本文で「ご判断くださ／い。」「お送りくださ／い」（`flow.html`、`kanri.html:88`）。
- `/credits/`・`/privacy/` の本文（`.doc`）が中央寄せの 820px で、左寄せのページヒーローと左端がそろっていない（1440px で 100px と 334px）。

### RefFidelity 13 / 15
- TOP の必須構造（HERO 文言・MICRO TRUST・PROBLEM・第二施工店・相談可能な工種例・業種別・FLOW 7 段・AREA・FAQ・FINAL CTA・FOOTER）はすべてそろっている。FLOW の工程名も要件どおり。今治の扱いも要件どおり。
- 減点: **/contact の必須項目が凍結文書と食い違っている**。freeze §5 は「必須: 会社名・担当者名・メール・物件所在地（市町）・依頼区分・内容。任意: 電話・物件種別・希望時期」だが、実装は電話・物件種別・物件の状況・希望時期まで必須で、計 11 項目（`contact.html:47, 75, 92, 111`）。
- 減点: 「送信前に対応外の例を短く表示」が、1023px 以下では送信ボタンの後ろに回っている（`.form-aside` が DOM でフォームの後ろにある）。

### Conversion 16 / 20
良い点: ヘッダー／ヒーロー／業種別の入口／各サブページ内の inline CTA／FINAL CTA／モバイル固定バーの導線ができている。`?type=` による区分の自動選択も動作を確認した。エラー要約（件数とアンカー付き）、写真アップロード（プレビュー・削除・D&D・形式とサイズのチェック）、本番接続前であることの明示もある。
