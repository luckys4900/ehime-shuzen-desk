## 0. 調査条件と制約（必読）

- 調査環境のネットワークは外向き通信が制限されており、**WebFetch によるページ取得はすべて失敗した**（例: data-max.co.jp / biz.ne.jp ともに `EGRESS_BLOCKED`）。
- そのため本書の内容は、**(a) WebSearch の検索結果スニペット** と **(b) 筆者（Claude）の一般知識としての業界サイト慣行** に基づく。実際のページ構成を目視確認したものではない。
- 各リファレンスの「確認方法」欄に、スニペットのみ／知識ベース／未確認 を明記する。
- 指定された Primary のうち複数は**検索で公式サイトを特定できなかった**。URL を推測で記載することはしない（未特定と記す）。

確認方法の凡例:
- **取得**: ページ本文を取得して確認（今回 0 件）
- **スニペット**: 検索結果の要約文のみで確認

## 4. 採用する原則（Adopted principles）

1. **発注者別の入口を最上部近くに置く**: 管理会社／買取再販／店舗・施設 の3入口をヒーロー直下に並べ、各サブページ（/kanri /kaitori /shop）へ送る。
2. **「写真を送る → 内容を確認 → 適した施工店へ振り分け → 見積・日程調整 → 施工 → 報告」の写真起点フロー**を番号付きステップで示す。各ステップには「誰が何をするか」を1行で書く。所要時間は書かない。
3. **CTA は2種類に固定**: 主＝「写真を添えて相談する（フォーム）」、副＝「電話で相談」。ヘッダー右上・ヒーロー・各主要セクション末・FINAL CTA に同一文言で反復。
4. **モバイルは画面下部固定の2分割バー**（電話／フォーム）。ヘッダーは電話アイコン＋メニューのみに縮約。
5. **サービスは「工事種別カード」＋「小さな作業の品目リスト」の二層**で示す（原状回復・内装補修・小修繕を主、建具調整・クロス部分補修等を品目で）。
6. **「第二施工店」という立ち位置を独立セクションで説明**: 既存の取引業者を置き換えるのではなく、手が回らない時・小さい案件・急ぎではない補修の受け皿である、と構造で示す。
7. **信頼は「事実の情報設計」で作る**: 対応エリア（地名リスト）、対応範囲／対応外の明示、受付時間、会社情報、依頼前に用意してほしいもの、FAQ。数値・実績・評価は使わない。
8. **フォームは段階的・最小限**: 必須は「会社名・担当者名・連絡先・物件所在地（市町まで）・依頼区分・内容・写真（任意だが推奨）」。物件種別・希望時期は任意。
9. **ビジュアルは抑制的な B2B トーン**: ベース（明るい中間色）＋濃色テキスト＋アクセント1色、見出しは太めのゴシック、本文は行間広め。写真がない前提で、アイコン・図解・余白で構成。
10. **対応外を先に書く**: 「対応できないこと（大規模改修の元請、緊急駆け付け等）」を FAQ または SERVICES 末尾に明記し、期待値を合わせる。

## 5. 採用しない（禁止）パターン（Rejected patterns）

当方の**真実性ポリシー**により、以下は事実の裏付けがないため一切使用しない。

| 禁止パターン | 典型例（一般形） | 理由 |
|---|---|---|
| 実績カウンター | 「施工実績◯件」「年間◯件」「協力業者◯社」 | 実績数値が存在しない／捏造になる |
| 顧客ロゴ・導入企業一覧 | 「主なお取引先」 | 取引先の事実がない |
| お客様の声・レビュー・星評価 | 「◯◯管理会社様より」 | 捏造レビュー禁止 |
| 24時間・365日・即日対応 | 「24h受付」「最短即日」 | 対応体制・速度の保証ができない |
| スピード・期間保証 | 「◯日以内に見積」 | 速度の約束は禁止 |
| 保証・アフター保証 | 「施工後◯年保証」 | 保証制度が存在しない |
| 許認可・資格の誇示 | 「建設業許可」「◯◯士在籍」 | 実在確認できない許認可は記載不可 |
| 沿革・創業年・スタッフ紹介 | 「創業◯年」「代表挨拶・顔写真」 | 歴史・人員の捏造禁止 |
| 価格の断定表示 | 「㎡単価◯円〜」「業界最安」 | 根拠のない価格・比較表現 |
| 「No.1」「地域最大級」等の比較優位 | — | 根拠なし・景表法上も不適切 |
| 他社の施工写真・素材の流用 | — | 著作権・誤認の問題 |

モックアップ上で数値や固有情報が必要な箇所は、**「（要確認）」「サンプル」と明示したプレースホルダ**にとどめる。
