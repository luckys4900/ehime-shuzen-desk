## 新しい指摘

### R12-1（P3）404 ページのメニュー「ご相談の流れ」がリンク切れ
- **場所**: `build.mjs` の 404 生成（`.replace(/(href|src)="(?!https?:|\/|#|mailto:|tel:)([^"]*)"/g, …)`）
- 404 のレイアウトは TOP（`slug: ''`）と同じものを使っているため、メニューの「ご相談の流れ」は `href="#flow"` になる。置き換えの対象から `#` で始まるリンクを除いているので、404 ページ内の `#flow`（存在しない）を指したままになる。他のリンクは `/ehime-shuzen-desk/…` に正しく置き換わっている。
- **結果**: 404 で「ご相談の流れ」を押しても何も起こらない（URL に `#flow` が付くだけ）。SP ではメニューが閉じるだけになる。全 6 幅で確認。
- **修正案**（1 行）: 404 の置き換えに `.replace(/href="#flow"/g, \`href="${BASE_PATH}#flow"\`)` を加える。あるいは `layout()` で、TOP 以外と同じく `../#flow` に相当するリンクを渡す。QA の 404 の検査に「ページ内リンクの飛び先がある」を加える。

### R12-2（P3）全角かっこ入りの電話番号を受け付けない
- **場所**: `src/assets/main.js` の `toHalfWidth` と `validateField`（`replace(/[\s()-]/g, '')`）
- 半角の `089(912)3456` は受け付けるが、日本語入力のまま打つと入る `（089）912-3456`（U+FF08 / U+FF09）は「電話番号は数字10〜11桁で入力してください。」になる。全角の数字・ハイフン・スペースは受け付けるので、扱いが揃っていない。
- **修正案**: `toHalfWidth` に `.replace(/[（）]/g, function (c) { return c === '（' ? '(' : ')'; })` を加える（または `/[\s()（）-]/g` で取り除く）。必要なら半角カタカナの長音 `ｰ`（U+FF70）もダッシュ類に加える。QA に 1 件追加する。

### 参考（減点なし）
- **別ページから TOP の「ご相談の流れ」へ移動したとき（390px）**: スムーズスクロールが終わった後、`#flow` の上端がヘッダーより 37px 上になり、見出しの上の「FLOW」がヘッダーに隠れる（見出しは見えている）。同じページ内での移動（84px）と 1440px（100px）は正常。ページの読み込み中にスクロール先が決まり、その後のフォントの差し替えで位置がずれるとみられる。気になる場合は、`location.hash` があるときに `document.fonts.ready` の後で `scrollIntoView` し直すとよい。
- 送信本文の電話番号は入力されたまま（`089−912−3456` など）で送られる。受け付ける側で表記ゆれが出るため、本番接続の際に正規化した値を送るか、受け付ける側で正規化すると扱いやすい。
- 404 の `canonical` と `og:url` が TOP の URL になっている。`noindex` のため実害はない。
- R11 で挙げた `docs/deployment.md` への送信先設定の 1 行の追記は、まだ反映されていない（任意）。
