# GPT（ChatGPT 等）でのレビュー手順

このサイトを、制作者とは別の AI に精査してもらうための手順です。

## 方法A：ファイルを添付する（確実）

1. 次のファイルをダウンロードします。
   - レビュー用バンドル（ドキュメント・全ソース・QA結果を1ファイルに集約）
     https://raw.githubusercontent.com/luckys4900/ehime-shuzen-desk/main/docs/gpt-review/review-bundle.md
   - 必要に応じてスクリーンショット（`docs/screenshots/` の PNG）
2. ChatGPT にファイルを添付し、下の「依頼文」を貼り付けて送信します。

## 方法B：URLを渡す（ブラウズ機能がある場合）

下の「依頼文」の先頭に次の1行を加えて送信します。

```
次のURLの内容を読み込んでからレビューしてください：https://raw.githubusercontent.com/luckys4900/ehime-shuzen-desk/main/docs/gpt-review/review-bundle.md
公開サイト：https://luckys4900.github.io/ehime-shuzen-desk/
```

## 依頼文（コピーして使用）

```
あなたは、日本の BtoB サービスのWebサイトを審査する独立レビュアーです。
添付（またはURL）のバンドルには、営業目的の異なる2つのサービスサイトが含まれています。両者を別々に、厳しく精査してください。

前提
- A「愛媛修繕デスク」（/repair/）：松山周辺の管理会社・買取再販事業者・店舗/施設運営者など法人向けの建物修繕の「第二施工店」。いつもの施工会社が手いっぱいの時の相談先。
- B「売却前おまかせデスク」（/sale-support/）：小規模の不動産仲介会社向けに、売却前の残置物・空室清掃・草刈り・小修繕の手配をまとめて受ける「第二の手配先」。
- どちらも既存の取引先の置き換えではなく、自社で施工・作業する会社ではありません。許可・資格が必要な業務は、必要な許可・資格を有する事業者を手配します。
- 2サイトは表側（文言・対象・色）を分け、フォーム・受け側（Google Apps Script）・計測は共通です。目的は「どちらの事業が案件化するか」を営業で比較することです。
- 事実確認ができない実績・顧客の声・件数・資格・許認可・対応スピード・保証・24時間対応・最安などは掲載しない方針です。運営者情報・電話番号・フォーム送信先・GA4 は未設定で、未設定の間は表示しません。

観点（A・B それぞれ10点満点）
1. 5秒で対象と用件が分かるか（A：法人向け建物修繕の第二相談先／B：不動産会社向け売却前作業の手配窓口）
2. 「いつもの業者を変える必要がない」ことが明確か
3. BtoB としての信頼感（誇張・誤認表現、許可・資格の扱い）
4. 案件相談フォームまでの自然さと入力の負担
5. A と B が「同じページの見出し違い」に見えず、別の営業商品として成立しているか
6. 技術（フォームのエッジケース、どちらのサイトの案件か判別できる仕組み、計測）

出力形式
- A・B それぞれの観点別の点数と理由
- HARD_FAIL（方針違反、許可・資格が必要な業務を無許可で受けられると誤認させる記述、プレースホルダ等）の有無と根拠
- 優先度順の改善提案（どのファイルのどこを、どう変えるか）
- 営業テストで比較する前に、事業者が確認すべき事項
```
