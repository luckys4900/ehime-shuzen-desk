# GPT（ChatGPT 等）でのレビュー手順

このサイトを、制作者とは別の AI に精査してもらうための手順です。

## 方法A：ファイルを添付する（確実）

1. 次のファイルをダウンロードします。
   - レビュー用バンドル（ドキュメント・全ソース・QA結果を1ファイルに集約）
     https://raw.githubusercontent.com/luckys4900/ehime-shuzen-desk/main/docs/gpt-review/review-bundle.md
   - 必要に応じてスクリーンショット（`docs/screenshots/` の PNG）
2. ChatGPT にファイルを添付し、下の「依頼文」を貼り付けて送信します。

## 方法B：URLを渡す（ブラウズ機能がある場合）

下の「依頼文」の先頭に次の1行を加えて送信します。

```
次のURLの内容を読み込んでからレビューしてください：https://raw.githubusercontent.com/luckys4900/ehime-shuzen-desk/main/docs/gpt-review/review-bundle.md
公開サイト：https://luckys4900.github.io/ehime-shuzen-desk/
```

## 依頼文（コピーして使用）

```
あなたは、日本の BtoB サービスのWebサイトを審査する独立レビュアーです。
添付（またはURL）の「売却前おまかせデスク」営業提案用サイトのバンドルを読み、以下の観点で厳しく精査してください。

前提
- 松山市周辺の小規模な不動産会社（1〜5名、相続物件・空き家、自社に作業班なし）向けに、売却前の残置物・空室清掃・草刈り・小修繕を「写真を送って」まとめて相談できる外部窓口のサイトです。
- いつもの業者を置き換えるものではなく、2番手・3番手の相談先という位置づけです。自社で作業する会社ではありません。
- KPI は案件相談フォームの送信数です。
- 事実確認ができない実績・顧客の声・件数・資格・許認可・対応スピード・保証・24時間対応・最安などは掲載しない方針です。「ご相談例」は架空の事例ではなく相談の流れの例です。
- 電話番号・フォーム送信先・GA4 は未設定で、未設定の間は表示・読み込みしません。フォームの受け側は Google Apps Script（backend/）で、未デプロイです。

観点と配点（合計100点）
1. 伝わるか（20）：不動産会社の社長が開いて数秒で「業者変更は不要」「どんな案件を頼めるか」が分かるか
2. 送信しやすさ（25）：写真付きフォームまでの導線、3段階フォームの負担、離脱要因、エラー表示
3. 信頼性（20）：誇張・誤認表現、廃棄物の許可・資格作業の扱い、足りない情報
4. スマートフォン（15）：読みやすさ・操作性、固定CTAが邪魔をしないか
5. 技術（15）：HTML/CSS/JS の品質、アクセシビリティ、フォームのエッジケース、Apps Script の堅牢性
6. 文章（5）：日本語として自然か、約束と読める表現がないか

出力形式
- 観点ごとの点数と理由
- HARD_FAIL（真実性ポリシー違反、許可・資格が必要な業務を無許可で受けられると誤認させる記述、プレースホルダ等）の有無と根拠（ファイル名・該当箇所）
- 優先度順の改善提案（どのファイルのどこを、どう変えるか）
- 本番投入前に事業者が確認すべき事項
```
