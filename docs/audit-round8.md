## 新規の指摘

### R8-1（P2）エラー要約の `role="alert"` が、キー入力のたびに書き換わる
- **場所**
  - `src/assets/main.js` の `refreshSummary()`
  - `src/pages/contact.html:22`（`role="alert"`）
- **再現手順**
  1. 空のまま送信する。
  2. 会社名を入力し、Tab で離れる（項目に `touched` が付く）。
  3. 会社名に戻って、4 文字追加で入力する。
- **結果**: 件数は 11 件のまま変わらない。それでも、要約の領域に **5 回の DOM 変更** が起きた（MutationObserver の計測）。
- **原因**: `input` イベントで `touched` の項目を再判定するたびに、`refreshSummary` が `box.innerHTML` を無条件に書き換えている。
- **影響**: `role="alert"` は、優先度の高い（assertive）ライブリージョンである。スクリーンリーダーでは、入力の 1 文字ごとに、11 件の一覧が読み上げ直される可能性がある。見た目への影響はない。
- **修正案**（数行で直る）
  - 生成した HTML が `box.innerHTML` と同じ場合は、書き換えない。
    - 例: `var html = summaryHtml(...); if (box.innerHTML !== html) box.innerHTML = html;`
    - または、無効な項目名を連結した文字列を `box.dataset.key` に持ち、比較する。
  - 可能であれば、即時の更新では `role="alert"` を外し、`aria-live="polite"` に切り替える。最初の送信時だけ assertive にする。
  - QA に、`touched` の有効な項目に 3 文字入力しても、要約の DOM 変更が 0 回であることの検査を追加する。
