仕入れ後

販売前に、内装を整えておきたい

壁紙や床の汚れ・傷など、内覧の前に整えておきたい箇所。写真をお送りいただければ、箇所ごとに内容を確認してご案内します。

範囲

どこまで手を入れるか迷っている

販売価格とのバランスを見ながら、工事範囲を段階的に検討したい。範囲ごとに分けた見積で、比べながらご判断いただけます。

  • 日程

    販売開始の予定が決まっている

    写真撮影や内覧の開始日に合わせて、工程を相談しながら進めたい。

  • 工種

    工種ごとに手配するのが手間

    内装、建具、外まわりなど、工種ごとに別々の会社へ連絡するのが負担になっている。

  • 記録

    工事の内容を記録に残したい

    どの箇所をどう直したかを、写真と見積の内訳で残しておきたい。

工事範囲の決め方

手を入れる範囲は、物件ごとに事業者様がご判断ください。判断しやすいよう、範囲ごとに分けて見積をご案内します。

工事範囲の段階と内容の例
必須工事販売に支障がある破損・不具合の補修。建具の開閉不良、床の大きな傷、壁の穴など。販売前に直しておくべき箇所
推奨工事汚れや色あせが目立つ壁紙・床材の張替え、ハウスクリーニングなど。内覧時の印象を整えるための工事
見送り可能な工事劣化した設備部品の交換や、部屋単位での内装の入替えなど。販売価格や方針に合わせて、見送るかどうかをご判断いただく工事。許可・資格が必要な工事は、必要な許可・資格を有する施工パートナーを手配できる場合に限ります

  1. 現地調査と施工可否の判断

    写真と物件情報から、施工できるかどうかと現地調査の要否をお知らせします。見積を出せる時期も先にご案内します。

  2. 必須・推奨・見送り可能に分けた見積

    工事を3つに分けて内訳をご提示します。設備や材料に代わりの選択肢がある場合は、あわせてご案内します。

  3. 販売開始日から逆算した工程

    販売開始や内覧の予定をお知らせください。複数の工種をまとめて調整し、可能な工程をご案内します。完了時は写真でご報告します。

お引き受けしていない内容

  • 間取り変更を伴う大規模なリノベーション
  • 構造に関わる工事、増改築
  • 設計・確認申請が必要な工事

内容によっては、施工パートナーを手配できない場合があります。その場合は、その旨をご連絡します。

ご相談時にあると判断しやすいもの

  • 部屋ごとの全体写真と、気になる箇所の写真
  • 間取り図（お手元にある場合）
  • 販売開始・内覧開始の予定日

仕入れ物件の手直しのご相談はこちら工事範囲が決まっていない段階でもご相談いただけます。

仕入れから販売開始までの流れ

販売開始・内覧開始の予定日をお知らせください。対応可否、現地調査の要否、見積を出せる時期を先にご案内し、可能な工程をご提案します。

ご相談を受け付けてから写真報告まで、次の12段階で進めます。各段階で、次に何が起きるかをお知らせします。

  1. PHASE 1受付・確認

    1. 案件受付送信後の画面に受付番号を表示し、担当者から、ご指定の電話またはメールに受付のご連絡をします。
    2. 内容確認写真・所在地・ご希望の時期を確認します。
    3. 対応可否の確認対応できる施工パートナーを確認し、対応可否と次のステップをご案内します。
    4. 必要情報の追加確認判断に足りない情報があれば、お問い合わせします。

  2. PHASE 2現地調査・見積

    1. 現地調査の要否判断写真で判断できるか、現地調査が必要かをお知らせします。
    2. 現地調査日の調整現地調査が必要な場合は、候補日を調整します。
    3. 見積提出予定のご案内見積までに時間が必要な案件は、先に提出予定をお知らせします。
    4. 正式見積必要な現地確認と施工パートナーの判断を経て、内訳つきの見積を提出します。

  3. PHASE 3発注・施工

    1. 発注見積をご確認・ご承認いただいてから発注となります。施工可能な時期もご案内します。御社
    2. 施工施工パートナーが施工します。予定の変更や確認が必要なことは、当デスクからご連絡します。施工パートナー

  4. PHASE 4完了

    1. 完了確認見積の項目どおりに終わっているかを確認します。
    2. 写真報告前後の写真と完了報告を、メールなどご指定の方法でお送りします。手直しのご連絡も当デスクが窓口です。

所要日数は、案件の内容と施工パートナーの状況によって異なります。そのため一律の日数はお約束せず、段階ごとに予定をご案内します。正式な見積は、必要な現地確認と施工パートナーの判断を経てから提出します。

よくあるご質問

仕入れ前の検討段階でも相談できますか？

ご相談いただけます。写真や間取り図など、分かる範囲の情報をお送りください。現地を確認できない段階では、概算でのご案内になる場合があります。

販売開始日までに間に合わせてもらえますか？

工程は、工事内容と施工パートナーの状況によって異なります。ご希望の日程をお知らせいただければ、対応できるかどうかを確認してご回答します。日程をお約束できない場合は、その旨をお伝えします。

空室で鍵を預ける形でも大丈夫ですか？

鍵の扱いや作業中の管理方法は、案件ごとに確認し、見積の前にお知らせします。
