店舗・施設運営者様からの
ご相談の場面

営業中の店舗や施設では、作業の時間帯や周囲への配慮が工程を左右します。条件を伺ったうえで、施工パートナーの手配を調整します。

営業中

床や壁の傷みが目立ってきた

客席や通路の床、壁の汚れや傷など、営業を続けながら直したい箇所。開店前・閉店後・定休日など、作業できる時間帯をお知らせください。

退店・移転

退店時の原状回復

テナント契約の終了に合わせた原状回復。範囲は契約内容や貸主様の指定によって決まるため、契約書や指示書の内容をあわせてお知らせください。

  • 建具

    扉や引戸の調子が悪い

    出入口や個室の扉の開閉が重い、閉まりきらないなどの不具合を相談したい。

  • 複数拠点

    店舗ごとに修繕先を探している

    松山周辺に複数の店舗や拠点があり、まとめて相談できる窓口がほしい。

  • 本部

    現地に担当者がいない

    本部から遠い店舗の修繕を、写真で状況を共有しながら進めたい。

お知らせいただきたい条件

営業中の店舗や施設では、作業の条件が工程と施工パートナーの手配に大きく関わります。分かる範囲でお知らせください。

分かる範囲で構いません。不明な点は、内容確認の際にこちらからお聞きします。

  • 営業時間・定休日作業できる曜日や時間帯（開店前・閉店後など）
  • 作業時の制約音・臭い・粉じんへの配慮、搬入経路、駐車場所など
  • 建物側のルール商業施設やビルの場合、工事申請や作業時間の決まり
  • 修繕内容修繕したい箇所と状態、写真
  • 希望時期改装・退店などの予定日

ご相談の前に確認しておきたいこと

  • 建物の管理会社・オーナーへの届出の要否
  • テナント契約で定められた原状回復の範囲
  • 工事中に使えなくなる設備や区画の有無
  • 作業当日に立会いができる方

作業時間について

営業時間外や定休日の作業をご希望の場合も、まずはご相談ください。施工パートナーの状況により、ご希望の日時で調整できない場合があります。

ご相談から
完了確認までの流れ

作業日時のご希望は、最初のご相談時にお知らせください。

ご相談を受け付けてから写真報告まで、次の12段階で進めます。各段階で、次に何が起きるかをお知らせします。

  1. PHASE 1受付・確認

    1. 案件受付送信後の画面に受付番号を表示し、担当者から、ご指定の電話またはメールに受付のご連絡をします。
    2. 内容確認写真・所在地・ご希望の時期を確認します。
    3. 対応可否の確認対応できる施工パートナーを確認し、対応可否と次のステップをご案内します。
    4. 必要情報の追加確認判断に足りない情報があれば、お問い合わせします。

  2. PHASE 2現地調査・見積

    1. 現地調査の要否判断写真で判断できるか、現地調査が必要かをお知らせします。
    2. 現地調査日の調整現地調査が必要な場合は、候補日を調整します。
    3. 見積提出予定のご案内見積までに時間が必要な案件は、先に提出予定をお知らせします。
    4. 正式見積必要な現地確認と施工パートナーの判断を経て、内訳つきの見積を提出します。

  3. PHASE 3発注・施工

    1. 発注見積をご確認・ご承認いただいてから発注となります。施工可能な時期もご案内します。御社
    2. 施工施工パートナーが施工します。予定の変更や確認が必要なことは、当デスクからご連絡します。施工パートナー

  4. PHASE 4完了

    1. 完了確認見積の項目どおりに終わっているかを確認します。
    2. 写真報告前後の写真と完了報告を、メールなどご指定の方法でお送りします。手直しのご連絡も当デスクが窓口です。

所要日数は、案件の内容と施工パートナーの状況によって異なります。そのため一律の日数はお約束せず、段階ごとに予定をご案内します。正式な見積は、必要な現地確認と施工パートナーの判断を経てから提出します。

店舗・施設の修繕のご相談はこちら作業日時の条件もあわせてお知らせください。

店舗・施設運営者様から

よくあるご質問

閉店後や定休日に作業してもらえますか？

ご相談いただけます。作業できる日時をお知らせください。施工パートナーの状況を確認のうえ、対応できるかどうかをご回答します。

商業施設内のテナントでも相談できますか？

ご相談いただけます。施設ごとに工事申請や作業時間のルールがあるため、施設側の決まりをあわせてお知らせください。

退店時の原状回復の範囲が分かりません。

原状回復の範囲は、テナント契約の内容や貸主様の指定によって決まります。契約書や貸主様からの指示書をご確認のうえ、内容をお知らせください。

状況が分かる写真と、物件の所在地・修繕内容をお送りいただければ、内容を確認のうえ担当者からメールまたはお電話でご連絡します。写真がない場合も、内容をご記入のうえご相談いただけます。
